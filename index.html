Real-Time Order Monitoring with Flink SQL

Learn stream processing hands-on: query a live stream of online orders, see how dynamic tables and changelogs work, and count orders per minute with watermarks and windows.

Step 1 · before the lab

Pre-work

Set up Confluent Cloud: a Kafka cluster, a topic and a Flink compute pool. About 30 minutes, browser only.

  • Create an account and a Kafka cluster
  • Create the orders topic
  • Set up a compute pool and check it works

Lab

Hands-on with Flink SQL on a live order stream. About 90 minutes.

  • Event time, watermarks and windows
